# Domain

Strapi is a headless CMS. It models content types, entries, administrators, roles and permissions, API tokens, and plugin-provided capabilities. Its server exposes REST and plugin APIs; the admin application configures and operates those capabilities.

The benchmark is not a product feature. It compares an agent's ability to locate the responsible Strapi package, preserve existing boundaries, and make a narrowly scoped, verified change.

The authoritative source remains code and tests in `apps/substrate`; these notes are orientation, not a replacement for source inspection.
