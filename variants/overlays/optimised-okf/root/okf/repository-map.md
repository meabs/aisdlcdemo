# Repository map

- `apps/substrate/`: pinned Strapi Community Edition source.
- `benchmark/tasks/`: fixed prompts and executable verifiers.
- `variants/`: configuration overlays and switcher.
- `benchmark/`: protocol, metrics, and result template.

The substrate is a Yarn 4/Nx TypeScript monorepo. Its root `package.json` is the command index. Preserve upstream licensing and do not edit benchmark configuration unless a task requests it.
